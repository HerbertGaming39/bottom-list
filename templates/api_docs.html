API Reference

REST API for the Bottom List — list levels, players, records, and more.

Authentication

Most endpoints require authentication. Authenticate by passing your API token:

Header

Set X-API-Token: <your_token> in the request headers.

Query parameter

Pass ?api_token=<your_token> as a query string parameter.

Get your token

GET /api/token — returns your API token (requires browser session). Use POST /api/token/regenerate to generate a new one.

You can also find your token on the Settings page.

Parameter Type Description
limit int Max results (varies by endpoint, default 20-200)
q string Search query
list string Filter by list type: main, challenge, platformer
status string approved, pending, rejected, or all
sort string Sort order: points (default), username
