Discord OAuth Setup

How to enable “Login with Discord” on this site.
1) Create an application
Go to the Discord Developer Portal → Applications → New Application.
2) Copy the Client ID and Client Secret
Open your application → OAuth2. Copy the Client ID and Client Secret. Keep the secret private.
3) Add a Redirect URI
Add this Redirect URI inside Discord Developer Portal → OAuth2 → Redirects:
{{ request.url_root.rstrip('/') }}{{ url_for('auth.login') }}
It must match exactly (http vs https, domain, port, and path). Don’t mix localhost and 127.0.0.1.
4) Put the values into Admin → Discord OAuth
In your admin dashboard, set:
Client ID: Discord Application Client ID
Client Secret: Discord Application Client Secret
Redirect URI: the URL above
5) Test
Open the login page. The “Login with Discord” button appears once all fields are set.
If you changed any Discord OAuth settings, restart your app so the changes are definitely active.
Troubleshooting
“Discord linking failed” immediately: redirect URI mismatch or state mismatch. Confirm the exact redirect URL above exists in both Discord and the Admin panel.
HTTP 403 / error code 1010: Discord/Cloudflare blocked your server-to-Discord request. This can happen on some IPs (VPN/datacenter) or local environments. Try using your real domain + HTTPS, and check the server log for the detailed warning line.
Where to check logs: look at your app output (for example: tail -n 200 logs/app.out if you start with nohup).
